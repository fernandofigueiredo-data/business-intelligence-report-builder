bi-html · plugin do Claude Code

Do dado ao BI, com cada número rastreável

Um plugin que fecha o ciclo planilha, análise, dashboard e documento de decisão dentro do Claude Code. O Claude desenha a página e escreve o texto; os valores vêm de uma camada de métricas determinística, com a definição de cada número ao lado dele.

Nenhum número sai do modelo de linguagem.

Como um número chega ao dashboard

  1. Planilha ou .pbix

    O arquivo original fica guardado com hash; tipos, datas no formato brasileiro e dados pessoais são conferidos.

  2. Camada de métricas

    Cada métrica tem definição escrita e linhagem; só ela calcula, no DuckDB.

  3. Spec sem números

    O Claude escreve a spec do dashboard: blocos e métricas por id, sem valores. Um schema impede algarismos no texto.

  4. HTML que só desenha

    O renderizador embute os números já calculados; cada bloco mostra "Como calculamos" e a tabela de apoio.

Todos os dados destas demonstrações são fictícios, gerados com semente fixa.
